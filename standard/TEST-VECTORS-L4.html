Reality2 Standard — Layer 4 test vectors

Status: Draft, PROVISIONAL in marked places. Date: 2026-08-05. Source of truth: L4-wire.md (12.2, 12.3). These vectors are generated by a generator held with the editing record, never hand-written; regenerate them and diff after any change to Layer 4.

Where a vector and the L4 prose disagree, one of them is wrong in public (L4 12.3 Note 2): file a defect report, do not pick one silently.

Cross-checked against an independently deployed implementation of the superseded corpus: FNV parameters and the HMAC span construction reproduce byte-for-byte; every divergence is a documented redesign.

Fixed inputs. HMAC key K = 000102030405060708090A0B0C0D0E0F101112131415161718191A1B1C1D1E1F (key derivation is Layer 5's, 10.3.1 — vectors state K explicitly). Hive/group wire values (origin, relay, target) are arbitrary literals: their derivation is the formats companion's (SS23/SS26) and any value is a valid wire form.

Ratified 2026-08-01 (formerly provisional): a tagged frame carries a route record with count >= 1 and GROUP_MGMT is never tagged (L4 10.1.4); a count-0 route record is origin-less and 8.1-type frames carrying one are dropped (8.3); route entries widen compact-to-extended by LOW-side zero-extension into the hive half (9.2.4); ambiguous crossings are refused rather than guessed (9.2.5) — XV2-XV4 are those refusals.

Provisional assumptions, each naming the open finding it rests on:

  • SS9: GROUP_MGMT payload bytes are opaque here; CBOR obligation unresolved.
  • SS62: GROUP_MGMT tier crossing is refused outright by implementations, but the text states neither refuse nor not-applicable; no vector asserts it.

N1–N6 hash alike (trim + fold); N11, N12 are distinct names (internal whitespace preserved; scripts outside the fold keep case). N10: U+00D7 is excepted from rule b. N14 exercises the exotic trim-set members U+2028/U+3000. N15: an INTERNAL non-ASCII whitespace (U+00A0) is part of the name — 7.1.2 trims edges only — so N15, N11 and N1 are three distinct names with three distinct hashes.
